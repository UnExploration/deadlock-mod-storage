Deadlock mod storage page

Deadlock mods can't write files. Mods made with deadlock-ai-mod-kit save their data (notes, marks, settings) by loading this page invisibly inside the game. The page keeps that data in this browser's own storage, on the player's PC, and sends nothing anywhere: it makes no network requests and runs no code from anywhere else.

Opened in a normal browser, as now, it does nothing. Each mod's data sits under the mod's own name, so mods don't see each other's data. Clearing Steam's web browser data (Steam > Settings > In Game) wipes it.

Warning: The kit's storage page is run by the kit's author, free, with no guarantee it stays online. If it goes away, mods that use it stop saving until their maker hosts the page at an address of their own, and data players saved under the old address does not carry over.
